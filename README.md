## Processes_LEAD_DATA.py
* This code extracts the data and removes all dashes from the downloaded lead dataset (Pre-processing data)

## Code_for_worst_day_of_outages.py
  * This code uses the EAGLE-I dataset and combines it with  Arizona's zipcode geospatial data. To calculate outages three methods are explored DOE, Abdelmalak et al, 2023, and a methods I create. The results are outputted as a shapefile(i.e., map).
